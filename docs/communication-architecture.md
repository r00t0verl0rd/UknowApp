# Сообщения и доступ

UknowApp хранит пользователей, роли, назначения, историю переписок и состояние прочтения. Telegram используется для связи с пользователями, но не заменяет базу приложения.

## Кто что видит

- **Администратор** управляет пользователями, назначениями и всеми диалогами.
- **Преподаватель** видит свои переписки с назначенными учениками и может отвечать в веб-панели или Telegram.
- **Ученик** видит доступные ему диалоги и может писать через веб-кабинет или подключённый Telegram.

Это **текущий набор ролей**, а не ограничение на будущее. Новые роли должны получать явно определённые права на просмотр, создание и отправку сообщений, привязку аккаунтов и работу с назначениями. Права проверяются на backend; отсутствие кнопки в интерфейсе не заменяет проверку доступа.

Для веб-входа преподавателям и ученикам администратор выдаёт логин и код доступа. Для привязки Telegram-аккаунта ученик получает отдельный одноразовый код, а преподаватель использует свой код доступа.

## Обработка сообщений

1. Сообщение приходит из веб-панели или Telegram.
2. UknowApp определяет отправителя, проверяет его права и принадлежность к диалогу.
3. Применяются проверки содержания; сообщение и состояние доставки сохраняются в SQLite.
4. Обновление передаётся в веб-интерфейс через SSE, а во внешние мессенджеры сообщение отправляется **каждому подключённому адресату независимо от привязки отправителя**. Если адресат не подключён, сообщение остаётся доступным в UknowApp.
5. Результат отправки во внешний канал сохраняется отдельно от статуса сообщения в UknowApp.

Внутренние статусы прочтения относятся к **веб-панели UknowApp**, а не к галочкам Telegram.

## Telegram и вложения

- Личные сообщения и сообщения из привязанной темы группы обрабатываются общими правилами.
- Ученик может писать в личный чат бота; преподаватель получает сообщения в своём чате с ботом и веб-панели.
- Для группы нужна супергруппа с темами и тема **«🤖 Бот»**. После привязки ученика первая запись в нужную тему связывает её с диалогом; командой `/bind_group` связь можно настроить вручную.
- Вложения сохраняются в собственный архив приложения. Возможность скачивания большого файла зависит от выбранного Telegram API: облачный — до 20 МБ; локальный — без этого ограничения Bot API.

## Где находится код

| Компонент | Путь |
| --- | --- |
| Унифицированные типы сообщений | `backend/app/modules/communication/contracts.py` |
| Отправка во внешние каналы | `backend/app/modules/communication/service.py` |
| Привязка аккаунтов | `backend/app/modules/communication/accounts.py` |
| Приём и проверка сообщений | `backend/app/modules/messaging/inbound.py` |
| Проверка контактных данных | `backend/app/modules/messaging/moderation.py` |
| Интеграция Telegram | `backend/app/modules/telegram/` |

Изменения бизнес-логики сообщений выполняются в общих модулях. Код Telegram отвечает за получение обновлений и работу с Bot API.
