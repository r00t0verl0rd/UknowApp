# Сообщения и права доступа

UknowApp хранит историю общения, пользователей, назначения и статусы прочтения. Telegram помогает доставлять сообщения, но не заменяет базу приложения.

## Роли пользователей

| Роль | Доступ |
| --- | --- |
| Администратор | Управляет пользователями, назначениями и всеми диалогами |
| Преподаватель | Общается с назначенными учениками через веб-панель или Telegram |
| Ученик | Общается в доступных ему диалогах через личный кабинет или Telegram |

При добавлении новой роли определите права на просмотр, создание и отправку сообщений, привязку аккаунтов и назначения. Все права проверяются на backend, а не только в интерфейсе.

## Вход и привязка Telegram

Для входа в веб-кабинет администратор выдаёт преподавателю и ученику логин и код доступа. Для Telegram ученик получает отдельный одноразовый код привязки, а преподаватель использует свой код доступа.

## Как проходит сообщение

1. Сообщение поступает из веб-панели или Telegram.
2. Сервер определяет отправителя, проверяет его права, диалог и содержание сообщения.
3. Сообщение и состояние доставки сохраняются в базе.
4. Веб-интерфейс получает обновление через SSE. Сообщение также отправляется каждому подключённому адресату во внешний мессенджер, независимо от привязки отправителя.
5. Результат внешней доставки сохраняется отдельно.

Если адресат не подключил Telegram, сообщение остаётся доступным в UknowApp. Статус прочтения в приложении относится к веб-панели, а не к галочкам Telegram.

## Telegram

- Ученик может писать в личный чат бота, преподаватель получает сообщения в своём чате с ботом и веб-панели.
- Для группового общения нужна супергруппа с темами и тема **«🤖 Бот»**.
- После привязки ученика первая запись в нужную тему связывает её с диалогом. Для ручной привязки есть команда `/bind_group`.
- Личные сообщения и сообщения из тем обрабатываются по общим правилам.

Вложения сохраняются в архиве приложения. Облачный Bot API позволяет боту скачивать файлы до 20 МБ, локальный API не имеет этого ограничения на скачивание.

## Где находится код

Все пути — относительно `backend/app/modules/`.

| Компонент | Файл или папка |
| --- | --- |
| Общие типы сообщений | `communication/contracts.py` |
| Доставка во внешние каналы | `communication/service.py` |
| Привязка аккаунтов | `communication/accounts.py` |
| Приём и проверка сообщений | `messaging/inbound.py` |
| Проверка контактных данных | `messaging/moderation.py` |
| Интеграция Telegram | `telegram/` |

Бизнес-логику меняйте в общих модулях. Интеграция Telegram отвечает за получение обновлений и работу с Bot API.
