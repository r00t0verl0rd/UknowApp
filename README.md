# UknowApp — локальный MVP школьной коммуникации

UknowApp — веб-панель администратора и Telegram-бот для приватного общения ученика с назначенным учителем. Backend: Python + FastAPI + SQLite. Frontend: React + Vite.

## Что уже реализовано

- Роли участников: администратор (панель), учитель, ученик.
- Создание учителей и учеников, редактирование профилей и активация/отключение.
- Генерация одноразового кода подключения Telegram из карточки пользователя: 8 символов, срок действия 15 минут, старые коды отменяются при выпуске нового. В базе хранится только хеш кода.
- Назначение ученика учителю. При переназначении прежняя переписка закрывается и сохраняется, создаётся новая.
- Переписка идёт через одного Telegram-бота: личные аккаунты учителя и ученика друг другу не показываются.
- Учитель выбирает нужный диалог кнопкой «Ответить» под сообщением ученика. Следующие сообщения учителя отправляются выбранному ученику.
- Пересылка основных типов сообщений Telegram выполняется методом copyMessage: текст, фото, видео, документы, голосовые, аудио, видеосообщения, стикеры, GIF и другие поддерживаемые Telegram типы.
- История сообщений и статусы доставки сохраняются в SQLite и доступны администратору.
- В админ-панели есть обзорные показатели, визуальная иерархия администратор → учителя → ученики, управление пользователями и просмотр переписок.
- Отправка контактов, email, телефонных номеров и Telegram-адресов блокируется простыми проверками текста. Содержимое контакта в базу не записывается.

## Требования

- Python 3.9+
- Node.js 18+
- Telegram bot token от BotFather (необязательно для запуска веб-панели; требуется для переписки через Telegram)

## Запуск на macOS / Linux

Из корня репозитория:

1. Создайте файл настроек:

   ~~~bash
   cp .env.example .env
   ~~~

2. Откройте .env и задайте свой пароль администратора. Для включения Telegram укажите токен:

   ~~~dotenv
   ADMIN_USERNAME=admin
   ADMIN_PASSWORD=ваш-длинный-пароль
   TELEGRAM_BOT_TOKEN=токен-от-BotFather
   ~~~

   Без токена веб-панель и API запускаются, но Telegram-бот не стартует.

3. Установите и запустите backend:

   ~~~bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r backend/requirements.txt
   uvicorn app.main:app --app-dir backend --reload
   ~~~

   API: http://127.0.0.1:8000  
   Документация API: http://127.0.0.1:8000/docs

4. В новом окне терминала установите frontend и запустите его:

   ~~~bash
   cd frontend
   npm install
   npm run dev
   ~~~

   Панель: http://127.0.0.1:5173

5. Войдите с ADMIN_USERNAME и ADMIN_PASSWORD из .env. При первом запуске база автоматически создаётся в data/uknowapp.db.

## Первый тест Telegram

1. Создайте бота через @BotFather и добавьте токен в .env.
2. Перезапустите backend, чтобы бот подключился через long polling.
3. В админ-панели создайте учителя и ученика, затем назначьте ученика учителю.
4. В списке пользователей нажмите «Код подключения» у учителя. Передайте этот код учителю.
5. Учитель открывает вашего бота, отправляет `/start`, затем отправляет полученный код отдельным сообщением.
6. Повторите те же действия для ученика: создайте отдельный код в его строке, попросите отправить его боту.
7. После подтверждения привязки ученик пишет боту. Учитель получает сообщение с кнопкой «Ответить». После нажатия можно писать ученику в том же личном чате с ботом.
8. Администратор видит историю в разделе «Переписки».

Код состоит из 8 символов (отображается с дефисом), действует 15 минут и используется один раз. При выпуске нового кода для того же пользователя предыдущие неиспользованные коды отменяются. Telegram ID автоматически сохраняется в профиль после успешной привязки; искать его вручную не требуется.

## Демо-данные

Чтобы проверить визуальную иерархию без заполнения формы, установите в .env:

~~~dotenv
SEED_DEMO_DATA=true
~~~

При пустой базе будет создан пример учителя и ученика без Telegram ID. Это только демонстрационные записи, переписка через них не заработает. Для чистого теста удалите data/uknowapp.db при остановленном backend и выключите seed.

## Полезные API маршруты

- POST /api/auth/login — проверка учётных данных администратора.
- GET /api/health — состояние backend.
- GET /api/admin/overview — показатели и данные для орг-графа.
- GET/POST /api/admin/users — список и создание участников.
- PATCH /api/admin/users/{id} — изменение имени, Telegram ID и статуса.
- POST /api/admin/users/{id}/connection-code — генерация одноразового кода привязки Telegram.
- POST /api/admin/assignments — назначение ученика учителю.
- GET /api/admin/conversations — список переписок.
- GET /api/admin/conversations/{id}/messages — история сообщений.

Защищённые маршруты используют HTTP Basic Auth. В браузере учётные данные хранятся только в sessionStorage текущей вкладки.

## Важные ограничения MVP

- Версия предназначена для локального тестирования на одном компьютере, не для публичного размещения.
- Для одного токена Telegram должен работать только один экземпляр backend/бота.
- Участники должны сами открыть бота и отправить /start: Telegram-бот не может первым начать личный диалог.
- Переносимые сообщения копируются от имени бота; Telegram-имя, username и телефон собеседника не показываются автоматически. Сам текст сообщения может содержать сведения, которые пользователь решил написать.
- Контакты, email, телефонные номера и Telegram-адреса блокируются простыми шаблонами. Это не полноценная модерация: изображения/скриншоты с контактами, ссылки на внешние соцсети и хитро замаскированные данные автоматически не распознаются.
- Вложения сохраняются в истории как тип сообщения и служебные метаданные; в админ-панели MVP пока нет встроенного проигрывателя/просмотрщика медиа.
- Админ-панель видит историю переписки, но отправка сообщений от имени администратора из панели не предусмотрена.
- Перед использованием с реальными данными несовершеннолетних потребуются HTTPS, индивидуальные учётные записи администраторов, аудит действий, резервное копирование, политика хранения и юридическая проверка.

## Структура

~~~text
backend/
  app/
    api.py             # REST API и админ-функции
    config.py          # локальные настройки
    database.py        # SQLAlchemy / SQLite
    models.py          # пользователи, назначения, переписки, сообщения
    security.py        # локальная HTTP Basic Auth
    telegram_bot.py    # aiogram 3, маршрутизация сообщений
    main.py            # FastAPI и запуск polling
frontend/
  src/
    App.jsx            # React админ-панель
    styles.css         # адаптивный интерфейс
data/                  # локальная база (создаётся автоматически)
~~~
