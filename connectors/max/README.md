# MAX-коннектор

MAX работает отдельным контейнером `uknow-maxbot` на сервере школы. Он принимает обновления по HTTPS через `/hooks/max`; публичный сертификат уже включён в образ.

Для настройки токена, `.env`, запуска и проверки используйте [руководство по подключению ботов](../../docs/bots-gateway.md). MAX нельзя запускать на отдельном сервере.
