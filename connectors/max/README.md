# MAX на сервере школы

Веб-кабинет работает самостоятельно. Для MAX заполните в локальном `.env` значения `MAX_BOT_TOKEN`, `MAX_WEBHOOK_SECRET`, `BOTS_NATS_MAX_PASSWORD`, `BOTS_MEDIA_SECRET_MAX`. Для каждого секрета используйте отдельную случайную строку (например, `openssl rand -hex 32`). Укажите путь к доверенному PEM-файлу удостоверяющего центра Минцифры в `MAX_CA_FILE`. Задайте публичное имя сайта в `DOMAIN`. MAX отправляет обновления на HTTPS-путь `/hooks/max` через Caddy.

При совместной работе укажите `BOTS_PLATFORMS=telegram,max` и сохраните текущие настройки Telegram. Для локального Telegram и MAX запустите:

```sh
docker compose -f docker-compose.yml -f compose.max.yml --profile gateway --profile bots --profile max up -d --build
```

При удалённом Telegram сохраните его текущие параметры Compose и добавьте к конфигурации сервера школы `compose.max.yml` и профиль `max`. В контейнер Telegram параметры MAX передавать не требуется.

Участник отправляет боту код из школы. Преподаватель выбирает переписку через `/menu` и `/open ID`. Для проверки используйте двух тестовых участников и проверьте сообщение и вложение в каждом направлении, доставку в оба мессенджера и отключение одного аккаунта в карточке участника.
