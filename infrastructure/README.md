# Развёртывание текущей ветки с NATS

Старый двухсерверный установщик WireGuard/NFS выведен из эксплуатации в этой ветке. Он закреплялся на исторической ревизии и не поддерживает независимые коннекторы. История доступна в Git; не запускайте старый установщик для текущего Core.

На предназначенном для тестирования VPS из корня репозитория:

```bash
bash infrastructure/deploy.sh --check
```

Команда только проверяет рабочее дерево, конфигурацию Compose и показывает состояние контейнеров. Она не подключается по SSH, не меняет firewall, не выполняет миграции и не запускает сервисы.

Для новой установки, обновления, отдельного VPS коннектора и проверки восстановления следуйте [Bots Gateway](../docs/bots-gateway.md) и [миграциям](../docs/database-migrations.md). Используйте отдельного тестового бота и копию БД. Не запускайте две версии Core на одной базе.
