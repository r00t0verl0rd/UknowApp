# Серверные команды

Для новой установки и обновления используйте инструкции из корня проекта: [README](../README.md) и [руководство по ботам](../docs/bots-gateway.md).

Проверить конфигурацию перед запуском можно так:

```bash
bash infrastructure/deploy.sh --check
```

Скрипт ничего не разворачивает и не подключается к другим серверам. Старый установщик WireGuard/NFS не поддерживается текущей веткой `test`.
